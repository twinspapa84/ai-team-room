# AI TEAM ROOM · 실시간 협업 회의실

지휘관(사용자) 1명이 안건을 던지면, 4명의 AI 팀원이 회의실 타임라인에서 차례로 핑퐁하며
최종 산출물까지 완성하는 **단일 HTML 웹앱**입니다. 외부 CDN·이미지·폰트 의존이 없습니다.

- 파일: `ai-team-room/index.html` (약 133KB, 인라인 CSS/SVG/JS)
- 검증: `ai-team-room/verify.py` — **179항목 전부 통과** (모바일 390×844 · 데스크톱 1280×800)
- 스크린샷: `downloads/ai-team-room-mobile.png`, `downloads/ai-team-room-desktop.png`

## 실행

```bash
# 방법 1 — 그냥 열기
open ai-team-room/index.html

# 방법 2 — 로컬 서버 (API 모드 권장: https/localhost에서 CORS·클립보드가 안정적)
cd ai-team-room && python3 -m http.server 8000
# http://localhost:8000
```

## 팀원 4명

| 팀원 | 색 | 역할 |
|---|---|---|
| 전략 | 오렌지 | 목표·타깃·핵심 포인트, 범위 고정 |

| 검수 | 퍼플 | 허점·과장·규정 위반 지적 → 카피/제작이 반영해 최종본 확정 |

## 두 가지 모드

### 1) 체험 모드 — API 키 불필요
- 프리셋 3종: ① 스레드 제휴 글 3줄 ② 동네 학원 숏폼 릴스 ③ 1인 부업 랜딩페이지
- 커스텀 안건: 키워드·유형(글/영상/랜딩/프로모션/서비스)을 자동 판단해 4명이 핑퐁
- 4명이 앞 발언을 직접 인용·반박하며 7~8개 발언 → 최종 산출물(체크리스트·리스크 포함)

### 2) API 모드 — OpenAI / Gemini / Claude
- 설정(⚙)에서 제공사·키·모델 입력 → **localStorage에만 저장**, 선택한 제공사 서버로만 전송
- 역할별 프롬프트로 4명 순차 호출(발언 → 반박/보완) 후, 전략이 최종 산출물을 마크다운으로 정리
- 회의 1회 = 5회 호출(4역할 + 정리). 오류 시 원인 안내 + **체험 모드로 이어서** 폴백
- **혼잡 대응**: 503·429·일시 네트워크 오류는 1.5초 → 3초 백오프로 **최대 2회 자동 재시도**.
  재시도 중에도 '중단'을 누르면 요청이 즉시 취소되고 오류 카드를 남기지 않습니다.
  Gemini는 503일 때 "구글 무료 서버가 잠깐 붐벼서 생긴 일시 오류입니다. 잠시 뒤 다시 눌러 보세요."로 안내합니다.
  연결 테스트는 15초에서 끊고 64토큰을 주어 thinking 모델에서도 빈 응답이 나지 않게 합니다.
- 연결 테스트 버튼, 제공사별 키 분리 저장, 마스킹 표시, 키 삭제

## 기능

- **지휘관 추가 지시**: 1차 회의 뒤 "말투 더 담백하게", "가격대 낮춰서", "더 짧게", "10대 타깃으로" 등
  → 팀원들이 추가 라운드로 반영, v2/v3로 갱신하고 `변경 이력`에 전후 비교를 남깁니다.
- **원클릭 복사**: 최종 산출물 Markdown 클립보드 복사(실패 시 execCommand 폴백)
- **회의록 .md**: 안건·모드·타임라인·최종 산출물 전체를 파일로 저장
- **회의 이력**: 최근 10세션 localStorage 저장 · 불러오기 · 개별/전체 삭제 · 새 회의
- **중단/빠르게**: 진행 중 회의를 멈추거나 즉시 완료
- **반응형**: 390px 아이폰(탭 전환: 회의실/결과물), 768px 태블릿, 1280px 2단 레이아웃
  - 입력창 16px(iOS 자동 확대 방지), `<label for>` 연결, safe-area 패딩, `100dvh`

## 주의

- API 키는 암호화되지 않은 브라우저 저장소에 남습니다. 공용 기기에서는 사용 후 삭제하세요.
- 제공사가 브라우저 직접 호출(CORS)을 막으면 오류가 날 수 있습니다. 그때는 체험 모드로 이어서 진행됩니다.
- 체험 모드는 규칙 기반 생성기입니다. 실제 LLM 품질이 필요하면 API 모드를 사용하세요.
